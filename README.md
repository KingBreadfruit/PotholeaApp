# PotholeaApp
An iOS app leveraging AI and LiDAR to detect and analyze potholes. Provides real-time pothole dimensions, repair costs, and resources needed using an intuitive interface integrated with Google Maps for precise location tracking. 

The EduceAI Pothole Detection App is an innovative iOS application designed to leverage cutting-edge AI and LiDAR technology to detect and analyze potholes in real-time. Developed for use with iPhones, this app targets municipal and civil engineering applications by providing detailed and accurate assessments of road conditions.

Key Features:

Pothole Detection: Utilizes a custom vision AI model to identify potholes in images with high precision. This model is integrated into iOS using Swift and leverages the LiDAR capabilities of newer iPhone models to capture detailed 3D dimensions of potholes.
Quantitative Analysis: After detection, the app uses OpenAI's powerful AI to analyze the data and provide a quantifiable assessment similar to that a human quantity surveyor would provide, including repair costs and necessary resources.
User Interface: A clean, intuitive UI designed to ensure ease of use while providing comprehensive data visualization. Users can snap photos, receive instant analytics, and view historical data and predictive maintenance schedules.
Collaboration and Reporting Tools: Features include reporting tools that allow users to send detailed reports directly from the app to local authorities or engineering teams.
Geolocation Integration: Incorporates Google Maps API for precise location tracking of potholes, enhancing the functionality of municipal planning and maintenance schedules.
The app is designed not only to facilitate the maintenance of road infrastructure but also to revolutionize how data is collected and utilized in urban planning and maintenance frameworks.
